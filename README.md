An entry for the make.fun micro-competition **Loading Screen Gold: A Tip in
200 Characters** — a single loading-screen tip for stressed developers and
AI coding agents, sharp and funny enough to land mid-build.

## Entry

> TIP: While this loads, the bug you are hunting is not in the code you are reading. It is in the code you skipped because it looked fine.

(136 characters, limit 200.)

## Run

```sh
python3 -P -s main.py
```

`main.py` is stdlib-only and resolves `entry.txt` relative to its own
location, so it runs from any working directory.
